# MimiVent App 回归检查清单

## 连接

- [ ] 启动后自动扫描；没有设备时显示扫描提示与重新扫描入口。
- [ ] 扫描到一台 MimiVent 时展示单设备卡片；连接状态、固件版本和设置同步完成后进入控制页。
- [ ] 扫描进行中点击设备；连接完成后旧扫描不能改写连接状态。
- [ ] 主动断开后再次扫描，列表只显示新一轮结果。
- [ ] App 后台停留少于 10 分钟后返回，连接仍可用。
- [ ] App 后台停留超过 10 分钟后返回，重新扫描并可再次连接。

## NAS MQTT 通道

- [ ] 已绑定设备且 NAS Gateway 可用时进入 NAS MQTT 控制，顶部徽标显示 `NAS MQTT 控制`。
- [ ] 关闭手机 WiFi 后 NAS Gateway 不可达，显示 `设备未连接`，不展示过期状态。
- [ ] 重新打开手机 WiFi 后自动恢复 NAS MQTT 控制。
- [ ] BLE 断开后可回到 NAS MQTT 控制；顶部名称和图标与蓝牙控制明显不同。
- [ ] NAS MQTT 控制页的自动感应、临时排风、临时暂停等验收入口均经 NAS Gateway 转发。
- [ ] NAS MQTT 控制页可读取/保存时间设置，统计今日/昨日/近三日/近七日可用。
- [ ] NAS 请求瞬时失败会重试；设备忙碌/限时任务/OTA 有明确提示。
- [ ] NAS MQTT 控制模式菜单不显示固件升级；切换蓝牙后显示并可进入。
- [ ] BLE OTA 安装后设备重启，App 能重新进入 NAS MQTT 控制。
- [ ] WiFi 配网、设备联网状态和局域网地址仍明确保留 WiFi 名称。
- [ ] BLE OTA 成功后顶部出现成功提示，设备已核验记录自动清除；暂停任务仍保留。

## 控制和配置

- [ ] 自动感应、临时排风、临时暂停、强制排风、持续关闭执行后状态和成功提示与设备一致。
- [ ] 相同限时操作再次点击立即重置时长，不排队。
- [ ] 有任务运行时选择不同任务：取消确认不改变设备；确认后中止旧任务并启动新操作。
- [ ] PIR 活动时普通临时排风停风；强制排风按定义忽略 PIR。
- [ ] 持续关闭可手动恢复自动感应。
- [ ] 环境不一致时锁定控制；切换设备和 App 跟随设备两条路径均正确。
- [ ] 修改、保存、重置时序只作用于当前环境。
- [ ] 断开、切环境或页面销毁期间结束的旧读取不会回填状态或触发错误通知。

## 窗口与视觉

- [ ] 窄屏竖屏：无横向溢出，主要卡片可纵向滚动。
- [ ] 横屏短高度：底部按钮与弹窗内容可滚动访问。
- [ ] 平板、折叠屏展开态、大窗口：主内容不无限拉宽，连接面板保持可读宽度。
- [ ] 统计图表选中今日/昨日时段：摘要右对齐，小于 1 分钟显示秒，达到 1 分钟显示分钟。
- [ ] 统计图表下方感应跨度与详情活动首末时差一致；单次触发不显示感应柱。
- [ ] 统计详情为感应 5 : 排风 5 双列时间线，邻近事件同行，单侧事件另一侧留空。
- [ ] 今日/昨日平均入厕时间使用固件汇总；有有效自动排风样本时不再显示 —。
- [ ] 操作卡片横向滑动时顶部标题不收缩。
- [ ] 大字号下确认弹窗和扫描列表仍能滚动并完成操作。

## 设备诊断

发版前统计与迁移专项：

- [ ] 真机 schema 6 满载升级到 7：最新 256 条事件保留，被淘汰日期显示容量截断，30 天日汇总不丢失。
- [ ] 设备 schema 5 选择最低可读 schema 6 的完整包或差分包时，升级与恢复任务均被阻止。
- [ ] 切换设备、BLE/NAS MQTT 通道或重置统计批次后，不显示旧设备/旧批次的范围数据。
- [ ] 旧数据不可用小时桶显示灰色斜线，选中该桶显示“不可用”。

- [ ] 未连接设备时，可从右上角菜单打开诊断页面；连接后也可从时间设置页进入。
- [ ] App 启动、扫描开始/结束、连接/断开和 GATT 服务发现有带毫秒时间戳的记录。
- [ ] 每次 BLE 请求能查看 TX 协议文本、RX 通知分包十六进制、解析后的 HTTP 状态/响应体和请求耗时；失败记录包含异常与已收到的数据。
- [ ] 日志在 App 重启后仍可查看，最多保留最近 300 条。
- [ ] 复制日志可粘贴出可读文本；清空操作经确认后生效。
- [ ] 日志不包含完整设备地址；Wi-Fi 凭证不通过 BLE 控制协议传输。
- [ ] 状态轮询默认只记录状态变化和定期摘要；开启原始抓取后会完整记录轮询收发，并在 5 分钟后自动结束。
- [ ] 高频日志不会每条都写入本地存储；清空日志后立即持久化空列表。
- [ ] 设备状态或时序配置缺少必需字段、类型错误、环境未知或时间值非法时，页面显示读取失败，不把无效值伪装为 0/关闭/正式环境。

阶段 4 已加入短屏面板高度、大字号状态卡布局、操作卡片自然高度和设置操作区换行。用户反馈当前 Android 手机验收无问题；平板、折叠屏与完整尺寸/字号矩阵尚未专项验证，未来扩展支持时补测。


## NAS MQTT 统计与事件分页

- 统计请求尚未完成时发起控制，确认控制没有等待该只读查询；同一 App 的多条控制仍串行执行。
- 今日事件首批读取失败后可点击重试；日期范围缓存有事件、旧版 mode 缓存为空时，下滑仍携带 nextCursor 继续分页。
- 每页显示加载状态；失败显示重试入口，末页显示全部可用事件；服务端游标未前进时停止自动分页并提示重试。
- 快速切换日期时，旧请求不得清除新范围的加载状态或把错误提示带到新日期。
- 设备末片 query-ack 到达后立即发下一查询，不应误报 QUERY_BUSY；同步 ACK 回调不得与分片发送形成查询锁/MQTT 客户端锁的反向等待。
- 对照诊断中的 queueMs、requestMs 和网关日志比较控制耗时，结果未知的控制仍保留 pending，不自动重发。

### NAS MQTT 快速切换与任务冲突

- [ ] 在今日查询尚未返回时连续切换昨日、前日、今日，已切走的排队范围与事件不再发出；当前范围最终退出“正在更新”。
- [ ] 相同范围并发刷新共同等待真实返回，不提前标记同步成功；查询失败向所有等待方传播。
- [ ] 已成功打开的日期在两分钟内切走再切回，立即复用缓存，不重复拉取汇总和首批事件。
- [ ] NAS 显示自动模式但设备已有新限时任务时，操作收到明确 409 后弹出“停止并切换”；取消不发送第二条，确认才携带 replace=1。
- [ ] ACK 超时或结果未知不能进入上述任务覆盖确认，也不能自动重发控制。

### MQTT 时间设置

- [ ] 正式／DEV 切换期间不显示环境不一致；切换完成后展示目标环境保存的五项时序，旧 NAS 快照不回退页面。
- [ ] 保存和重置显示正在执行，未知结果才显示待确认；拒绝或未知结果不能提示保存成功。
- [ ] 未连接 BLE 时，MQTT 重置仍可执行；production 默认值为 30000/30000/120000/60000/300000 ms，dev 为 5000/0/10000/10000/10000 ms（顺序：冷静期、离开确认、自动排风、临时排风、暂停）。固件 SettingsStore.cpp 默认值变更时同步 App 默认值。
