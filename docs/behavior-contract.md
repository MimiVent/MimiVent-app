# MimiVent App 行为约定

## 连接与生命周期

- 在线启动优先核验已有 WiFi 绑定；成功后使用 WiFi，失败后进入 BLE 连接流程。主动离线模式不自动连接。
- 搜索界面显示扫描数量。只发现一个设备时展示设备卡片；发现多个设备时显示选择列表。
- 扫描中切换到连接时，旧扫描完成回调不能把连接状态改回断开。
- 短暂切后台最多保留 10 分钟 BLE 会话；超时后断开，回到前台启动新的扫描。
- 断开或 App 销毁后，旧状态请求结果不能重新填充已断开的设备卡片。

## WiFi 配网与通道

- 配网凭据仅通过加密且已 bonding 的 BLE 通道发送；手机扫描网络，设备不扫描。
- WiFi 有 IP 不等于 App 已绑定；证书、token 和设备身份核验成功后才可控制。
- 同一时刻只有一个 WiFi 主控租约，其他手机可经 BLE 或等待接管；OTA 仅走 BLE。
- 手动选择通道与主动离线需保留用户意图，设备执行结果不能因切换通道而重复提交。

## 设备操作

- 自动感应、临时排风、临时暂停、强制排风、持续关闭由固件执行。
- 临时排风期间 PIR 活动会立即停止风机；强制排风会忽略 PIR，但仍受固件限时保护。
- 再次点击相同临时排风、暂停或强制排风，从本次点击时刻重新计时，不排在现有计时后面。
- 覆盖正在执行的其他流程时，先确认。取消确认不发命令；确认后才停止旧流程并执行新动作。
- 持续关闭会使风机保持关闭，直到用户明确恢复自动感应。
- 设备离线、环境不一致或命令正在执行时，不显示成功状态；应提供清晰的阻止或失败反馈。

## 环境与设置

- App 保存本地环境选择；固件报告设备当前环境。
- 两者不一致时控制操作锁定。用户可以切换设备到 App 所选环境，或让 App 跟随设备。
- 正式和 DEV 配置相互独立。设置修改只保存在草稿中，点击保存才发送给固件；重置仅作用于当前环境。

## 布局

- 手机窄屏允许纵向滚动；快捷动作区横向滚动。
- 平板、折叠屏与桌面大窗口限制主体最大宽度，避免内容铺满过宽区域。
- 小屏宽度下 PIR 与风机指标纵向排列；空间足够时并排。
- 设备扫描弹窗限制高度，设备列表可滚动；横向滚动不驱动页面标题收缩。
