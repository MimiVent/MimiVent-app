# MimiVent Android App

MimiVent 的 Android 控制端，支持 BLE 控制、安全 BLE 配网和局域网 WiFi HTTPS 控制。控制、时间设置、统计共用设备业务接口；固件升级使用独立 BLE OTA 通道。

当前版本：`v0.5.1`（`0.5.1+9`），配套固件 `v0.5.1`。此前正式 App 版本为 `v0.3.0`；WiFi 开发期间的 `0.4.x` 调试包统一归入本次更新，不作为独立正式发布。变化见 [CHANGELOG.md](CHANGELOG.md)。

## 主要功能

- **控制**：查看 PIR、风机、运行阶段、本轮运行时间和剩余时间；支持自动感应、临时排风、临时暂停、限时强制排风、持续关闭。
- **时间设置**：分别保存正式/DEV 环境的启动冷静期、离开确认、自动排风、临时排风和暂停时长，支持恢复默认值。
- **统计**：查看今日、昨日、近 3 天、近 7 天运行时长与图表，今日/昨日事件支持分页和本地缓存；今日指标可与昨日比较，指标卡支持横向滑动；柱图上方为排风、下方为感应跨度，今日/昨日可按 5:5 双列时间线查看排风与感应详情。
- **连接**：顶部显示实际控制通道；已有有效 WiFi 绑定时优先尝试 WiFi，失败后进入 BLE 连接流程；支持手动切换通道与离线查看。
- **升级**：签名完整包/差分包、压缩传输、暂停续传、独立安装确认、重启后身份核验及升级任务放弃/替换；成功后顶部提示并自动清除已核验记录，暂停中的任务继续保留。
- **诊断**：查看、复制和清空日志；日志自动写文件，按日期及大小切片，超过数量上限自动清理旧文件。

设备是运行状态的事实来源。控制指令经设备确认后更新界面；覆盖任务、切换设备环境、持续关闭等操作需要确认。设备离线时不会积压控制指令，也不会在重连后自动补发。

## 首次连接、配网与绑定

1. 打开 App，通过附近设备弹窗连接 `MimiVent` 蓝牙设备；按系统提示授予附近设备/蓝牙权限。
2. 打开菜单中的 WiFi 配网入口。Android 手机负责搜索附近 2.4 GHz 网络，选择网络后输入密码；也可手动填写隐藏网络。设备不执行 WiFi 扫描，避免 BLE/WiFi 共存时的内存高峰。
3. 首次访问安全配网通道时，按系统提示完成蓝牙配对。当前使用加密 bonding，不提供自定义六位码，也不执行 MITM 身份认证；请在可信设备附近完成配网。
4. 设备接入路由器后完成本机绑定和 HTTPS 身份核验，才可通过 WiFi 控制。设备有 SSID/IP 不等于 App 已获得控制权限。
5. 配网可跳过，之后仍能通过 BLE 控制；配网成功后自动尝试绑定，绑定失败可通过管理入口恢复。

手机搜索按需申请精确位置权限，并要求手机 WiFi、系统定位开启；系统限流时可能使用带时间标记的缓存。支持 2.4 GHz WPA2-Personal 和 WPA2/WPA3-Personal 混合网络；开放网络、企业认证和纯 WPA3 不在当前支持范围。密码仅经加密 BLE 配网通道发送，不保存到 App，不写日志。两次主动搜索至少间隔 30 秒；等待 12 秒未完成时可读取缓存并标注结果年龄。同名网络合并并按信号排序；手机能搜索到不保证设备所在位置也能连接。

## WiFi 控制与多手机使用

- 手机与设备需在同一可互访局域网；访客网络或 AP 隔离可能阻止访问。
- HTTPS 端口为 `8443`，使用设备证书 DER 指纹固定、Bearer token 和设备身份校验；本机绑定通过 Android Keystore AES-GCM 加密保存，不备份到其他手机。
- WiFi 支持状态、设置、控制、统计及事件查询。菜单“连接蓝牙（备用）”可切换 BLE，“切换回 WiFi 控制”可恢复 WiFi。
- 每台设备最多保留三个 WiFi 绑定，但同时只有一个 WiFi 控制租约，空闲超时为 20 秒；其他手机可走 BLE，或等待原租约释放/过期再接管。绑定数量不等于可同时占用的 WiFi 控制数。
- HTTPS 服务单连接，App 请求串行化并优先处理用户操作；读请求与健康检查有重试策略。写请求通过请求 ID 查询执行结果，避免超时后直接重复执行。
- 手动切换 BLE 后尊重用户选择；双通道均不可用时提示重新连接。离线查看会停止自动连接，设备继续按原模式运行。
- 设备诊断中的 WiFi 管理入口支持查看绑定、逐个撤销及清除设备端全部绑定。旧手机丢失、卸载或清数据导致本地凭据丢失时，可经安全 BLE 清除旧授权后重新绑定；仅重置本机存储不会撤销设备端授权。
- **OTA 只走 BLE**。WiFi 控制模式会隐藏固件升级入口，需先切换/连接蓝牙再升级。
- 校时仍经 BLE 完成；当前 HTTPS 路由不提供 `/api/time`。设备断电后尚未获得可信时间时，日期统计需等待校时。

## 统计口径

- 风机累计运行时长包含自动、临时及强制排风；事件明细和运行汇总独立保留，明细淘汰后仍可能存在运行汇总。
- 感应次数是 PIR 触发次数，不等于人数或入厕次数。相邻活动按当前自动排风时长限制分组合并。
- “预计入厕”优先显示固件返回的 `toiletCount`；只依据自动排风估算，实际时长达到设定时长一半时计入，手动/强制排风不计入。旧固件缺少字段时按已下载明细估算，明细不足时可能显示“—”。
- “平均入厕时间”是根据已下载的有效自动排风明细计算的估算值，并非实际停留时长，也不是独立测量的人均时长；样本不足时显示“—”，分页加载可能改变结果。
- 各统计范围按设备和数据批次缓存，离线显示最后成功快照及更新时间；快照里的“运行中”不代表设备当前仍在运行。

## BLE 与 OTA

当前控制使用 BLE v2：请求包含关联 ID，响应按帧重组并检查长度/校验值；业务内容仍复用同一 API 语义，不是旧版纯文本通知协议。

| 通道 | UUID |
| --- | --- |
| 控制服务 | `6f9b0001-7d5a-4c3b-9a21-2f6d4d494d49` |
| 控制命令 / 响应 | `6f9b0002-7d5a-4c3b-9a21-2f6d4d494d49` / `6f9b0003-7d5a-4c3b-9a21-2f6d4d494d49` |
| OTA 命令 / 数据 / 状态 | `6f9b0004-7d5a-4c3b-9a21-2f6d4d494d49` / `6f9b0005-7d5a-4c3b-9a21-2f6d4d494d49` / `6f9b0006-7d5a-4c3b-9a21-2f6d4d494d49` |
| 安全配网服务 | `6f9b0010-7d5a-4c3b-9a21-2f6d4d494d49` |
| 安全配网命令 / 响应 | `6f9b0011-7d5a-4c3b-9a21-2f6d4d494d49` / `6f9b0012-7d5a-4c3b-9a21-2f6d4d494d49` |

菜单打开“固件升级”，选择签名 `.mvota` 完整包或匹配当前镜像基线的 `.mvdelta` 差分包；不接受原始 `.bin`。流程为：选择 → 上传/续传 → 完整校验 → 确认安装 → 重启 → 重连核验版本及固件身份。上传 100% 仅表示传输完成。升级期间保持前台和稳定供电。

设备验证 SHA-256 与 RSA-PSS 发布者签名，App 负责包结构检查及传输。允许兼容范围内的受控降级，仍受签名、目标芯片、分区与版本兼容限制；不能仅修改文件名伪装版本。BLE OTA 需使用正确双 OTA 分区布局，旧布局首次迁移需 USB 烧录。

## 开发环境与构建

保持现有构建链，无需升级 Gradle 或 Java：

| 项目 | 当前配置 |
| --- | --- |
| Flutter / Dart | `custom_3.22.0_harmony`：Flutter `3.22.1-0.0.pre.28` / Dart `3.4.0` |
| Java | JDK 11 |
| Gradle / AGP / Kotlin | `7.6.3` / `7.3.0` / `1.7.10` |
| 平台 | Android；其他平台未随本版交付 |

```sh
export JAVA_HOME="$(/usr/libexec/java_home -v 11)"
flutter pub get --enforce-lockfile
flutter analyze
flutter build apk --release
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

仅构建 ARM64 手机包可追加 `--target-platform android-arm64`。Release 当前使用 Debug 签名，供家庭内部安装；后续覆盖更新需保持相同签名并递增构建号。公开分发前另行配置长期 Release keystore，私钥及密码不得入库。

单元测试使用 `flutter test`。如果当前定制 SDK 缺少 `flutter_tester`，应在隔离测试副本中使用可运行测试的 SDK，避免改写主项目依赖锁文件；回到项目 SDK 完成分析与 APK 构建。

## 日志文件

诊断页内保留最近 300 条，状态轮询默认记录变化及每 30 秒摘要；完整原始状态抓取最多持续 5 分钟。文件日志为 JSON Lines，分别记录发生时间和写入时间（含时区），按日期及 1 MiB 上限切片，最多保留 10 个文件，自动删除最旧分片。

Android 优先写入应用专属外部目录，通常为：

```text
/sdcard/Android/data/dev.mimivent.mimivent_app/files/MimiVent/logs/
```

实际目录以启动日志/诊断页为准；外部目录不可用时回退到应用支持目录。可用 ADB 拉取文件，无需逐页翻看；密码、token 等敏感信息不得写日志。

## 代码与维护

- `lib/ble/`：BLE 协议、GATT 调度、扫描连接与 OTA 传输。
- `lib/data/`：设备状态、连接通道、会话、统计缓存和设置草稿。
- `lib/features/wifi_provisioning/`：手机网络选择与安全 BLE 配网。
- `lib/features/wifi_control/`：加密绑定、HTTPS 传输、绑定恢复和管理。
- `lib/features/firmware_update/`：包解析、任务持久化、阶段与安装交互。
- `lib/features/statistics/`：范围查询、事件分组、比较和图表。
- `lib/core/diagnostics/`：本地诊断与文件日志。
